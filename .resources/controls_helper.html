Key Concepts for Drivers

Shooting Sequence

  1. Hood auto-adjusts angle by distance
  2. Hold R Trigger (C1) to align robot
  3. Robot auto-rotates toward hub/pass spot
  4. When yaw + hood are on target, balls fire
  5. Release trigger → hood returns to default

Intake Sequence

  1. Press R Bumper (C2) to deploy intake
  2. Hold L Trigger (C2) for roller forward
  3. Drive into fuel (yellow balls)
  4. Press L Bumper (C2) to undeploy
  5. Or: trench paths (X/B on C1) auto-deploy intake

Safety / Auto Features

  • Hood clamps to MAX_POSITION (35 deg)
  • Hood auto-adjusts by distance (default cmd)
  • PID updates blocked on FMS
  • Force-apply PID: Back+Start (C1)
  • POV Up (C1) resets field-centric heading
  • POV L/R (C1) seeds odometry to corners

Quick Tips

  • R Bumper (C1) is a modifier — holding it changes X and B from trench paths to precise DriveToASpot commands (left/right trench feed positions).
  • L Bumper (C1) drives to the shooting spot AND spins up the shooter in parallel — release to stop.
  • Hood auto-correction runs continuously as the default command via UpdateHoodPositionVariable. POV Down (C2) overrides to outer ring position.
  • Shooting won't fire until both the robot yaw AND hood angle are within tolerance of the target — prevents wasted shots while the robot is still turning or the hood is still moving.
  • Slip current is set to 54A (reduced from 120A default) to prevent wheel slip and brownouts.
  • All tunable values (PID, hood max, intake speeds) are editable on the Elastic dashboard. Use elastic-layout-v2.json.
  • Odometry helpers: POV Left/Right (C1) let you seed robot position to back-left or back-right field corners when AprilTag vision is unavailable.
