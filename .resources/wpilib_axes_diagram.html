⚠ Common Gotchas for RobotPy / your codebase

Controller Y is inverted getLeftY() returns -1.0 when stick is pushed up/forward. That's why drivetrain.py uses -controller.getLeftY() for velocity_x.
Field flipping (Red alliance) On Red alliance, FlipUtil.fieldPose() mirrors X only (field_length - x). Y should not be flipped — check flip_util.py for the Y-flip bug noted in the review.
Phoenix 6 velocity = RPS motor.get_velocity().value returns rotations per second, not RPM. Divide RPM constants by 60: kShooterMotor.TARGET_RPM / 60. The is_charged comparison in dual_shooter.py still compares RPS to RPM directly — needs fix.
Swerve rotation = rad/s with_rotational_rate() takes radians/second. Your code multiplies the PID output by kDriveConfig.MAX_ANGULAR_RATE to scale from [-1,1] to rad/s — correct.
Heading convention drive_state.heading is degrees (-180 to +180), CCW positive, 0° = facing +X field direction. The PID uses enableContinuousInput(-180, 180) — that's correct, and the accuracy check now uses the angle-wrap fix (error + 180) % 360 - 180.
