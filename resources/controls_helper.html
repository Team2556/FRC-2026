Key Concepts for Drivers

Shooting Sequence

  1. Hood auto-adjusts angle by distance
  2. Hold R Trigger to align robot
  3. Robot auto-rotates toward hub/pass spot
  4. When yaw + hood are on target, balls fire
  5. Release trigger → hood resets home

Intake Sequence

  1. Hold R Trigger (C2) or Both Bumpers (C1)
  2. Intake deploys forward + spinner starts
  3. Drive into fuel (yellow balls)
  4. Release → undeploy (3s timeout safety)
  5. Spinner uses NeutralOut to stop cleanly

Safety / Auto Features

  • Hood clamps to MAX_POSITION (35 deg)
  • Hood retracts near bumps/trench zones
  • Undeploy has 3s timeout if limit fails
  • PID updates blocked on FMS
  • Force-apply PID: Back+Start

Quick Tips

  • Both bumpers on C1 deploys intake — the individual bumper commands (GoBack, Shooter) have .negate() guards so they won't fire when both are held.
  • Hood auto-correction runs continuously as the default command. Manual stick (C2 right X) overrides it. In the danger zone (transition X: 3.5–5.7m or 10.86–13.07m), the hood automatically retracts.
  • Shooting won't fire until both the robot yaw AND hood angle are within tolerance of the target — prevents wasted shots while the robot is still turning or the hood is still moving.
  • Slip current is set to 54A (reduced from 120A default) to prevent wheel slip and brownouts.
  • All tunable values (PID, hood max, intake speeds) are editable on the Elastic dashboard. Use elastic-layout-v2.json.
